1. Cadastrar música

Dados opcionais da música

2. Biblioteca e processamento de áudio

Envie a música original. Os arquivos são enviados ao armazenamento local do TV Box. Envie arquivos MP3 separados: original, instrumental, voz principal e segunda voz. A separação por IA depende de um backend específico e não é executada por esta API de armazenamento.

API pública HTTPS do MXQ Pro. As cantoras podem reproduzir os arquivos pelo celular sem instalar Tailscale.

O envio ao TV Box utiliza a mesma autenticação Google do painel. Somente administradores autorizados podem enviar arquivos.

Não coloque token secreto neste campo. A API recebe um token de sessão Firebase pelo cabeçalho Authorization.

Carregando músicas…

Limite importante: o processamento pode produzir um playback instrumental e uma faixa vocal combinada. Para treinar voz principal e segunda voz de modo independente, cadastre também duas referências vocais separadas. O resultado de IA precisa ser ouvido e aprovado; não há garantia de qualidade de gravadora.
